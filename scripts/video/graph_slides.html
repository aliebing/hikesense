How to explain it to the panelSo erklärt man es dem Panel

  • A LangGraph state machine: 12 nodes, one typed State, a checkpointer per thread.
  • Eine LangGraph-Zustandsmaschine: 12 Knoten, ein typisierter State, ein Checkpointer pro Thread.
  • One structured model call understands the message; code checks it and sets the route.
  • Ein strukturierter Modellaufruf versteht die Nachricht; der Code prüft sie und setzt die Route.
  • Tour searches: the graph calls the search itself; the model only words the result.
  • Tourensuche: Der Graph ruft die Suche selbst auf; das Modell formuliert nur das Ergebnis.
  • Open knowledge questions: a ReAct loop, the model calls 4 tools, at most 8 times.
  • Offene Wissensfragen: eine ReAct-Schleife, das Modell ruft 4 Tools auf, höchstens 8 Mal.
  • Every number is checked against tool results before it is shown.
  • Jede Zahl wird gegen Tool-Ergebnisse geprüft, bevor sie erscheint.

The code decides, the model words it.Der Code entscheidet, das Modell formuliert.
