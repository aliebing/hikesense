Division of labour

The code decides, the model words it

Model

  • message → structured request (one call)
  • answer text from the tool results
  • tool choice for knowledge questions

Code

  • keeps a number only if the user wrote it
  • resolves places, asks when ambiguous
  • searches and checks every condition
  • near misses and fallbacks
  • day plans, walking time to DIN 33466
  • honest sentences: “No tour meets all your wishes, because …”

Conditions

Matches, near misses, fallbacks

✓ ✗ ? per condition

length · ascent · round walk · distance · duration

Near miss

fills 1–2 matches up to 3 · exactly one condition, missed by ≤ 25 % · never the round walk

Fallback

no match: tours that break exactly one condition, best per condition · reason written by the code
